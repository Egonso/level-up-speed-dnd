# Szenarien

## 1. Der Tresor der Mitternachtsbank

Pitch: Die Gruppe soll ein versiegeltes Artefakt aus einer magischen Bank holen. Während sie eindringen, erschüttert ein Erdbeben den Tresortrakt.

Bossraum: Der Tresorwächter erwacht. Gewinnen heißt: Wächter besiegen oder das Artefakt stehlen und 2 Runden lang den Ausgang halten.

Zeitdruck: Nach dem dritten aufgedeckten Raum zieht der DM jede Runde 1 Chaoskarte.

Klassenziele:

| Klasse | Ziel |
| --- | --- |
| Rogue | Öffne einen Sicherheitsmechanismus ohne Alarm. |
| Bard | Überzeuge eine panische Person, euch zu helfen. |
| Fighter | Halte eine Engstelle eine Runde lang allein. |
| Wizard | Entschlüssle ein Tresorsiegel. |
| Druid | Stabilisiere einen rissigen Steinbogen mit Naturmagie. |
| Barbarian | Breche eine blockierte Tür auf, ohne die Gruppe zu verletzen. |

## 2. Das Ei im Kristallhort

Pitch: Ein Drachenei wurde gestohlen und in einen Kristallhort gebracht. Die Gruppe muss es finden, bevor die Magie darin kippt.

Bossraum: Der Horthüter verteidigt das Ei. Gewinnen heißt: Horthüter besiegen oder das Ei 3 Felder weit aus dem Ritualkreis tragen.

Zeitdruck: Jedes Mal, wenn eine Falle ausgelöst wird, steigt die Ei-Instabilität um 1. Bei 3 Instabilität bekommt der Boss +1d6 Schaden auf seinen nächsten Angriff.

Klassenziele:

| Klasse | Ziel |
| --- | --- |
| Rogue | Finde einen sicheren Pfad durch die Kristallsplitter. |
| Bard | Beruhige das vibrierende Ei mit Klang oder Worten. |
| Fighter | Blocke einen Treffer gegen einen Träger des Eis. |
| Wizard | Unterbrich ein arkanes Ritual. |
| Druid | Erkenne, was das Ei braucht, ohne es zu beschädigen. |
| Barbarian | Trage das Ei oder einen Felsblock trotz Gefahr weiter. |

## 3. Die Glocke unter der Akademie

Pitch: Unter einer magischen Akademie steht ein Uhrwerk still. Wenn die Alarmglocke voll schlägt, werden alle im Gebäude eingefroren.

Bossraum: Der Uhrwerk-Verwalter will die Glocke auslösen. Gewinnen heißt: Verwalter besiegen oder 3 erfolgreiche DC-14-Checks am Uhrwerk schaffen.

Zeitdruck: Am Ende jeder Runde im Bossraum steigt der Glockenzähler um 1. Bei 4 wird eine Chaoskarte sofort ausgelöst.

Klassenziele:

| Klasse | Ziel |
| --- | --- |
| Rogue | Deaktiviere ein Zahnrad, bevor es jemanden trifft. |
| Bard | Halte die Gruppe trotz Lärm koordiniert. |
| Fighter | Schütze die Person, die am Uhrwerk arbeitet. |
| Wizard | Erkenne die richtige Reihenfolge der Runen. |
| Druid | Spüre den unnatürlichen Rhythmus der Maschine. |
| Barbarian | Stoppe ein drehendes Rad mit roher Kraft. |

## 4. Der Schattenpass

Pitch: Die Gruppe begleitet einen kleinen Wagenzug durch einen Gebirgspass. Im letzten Tunnel wartet der Anführer des Überfalls.

Bossraum: Der Schattenhauptmann hält den Passausgang. Gewinnen heißt: Hauptmann besiegen oder den Wagen 6 Felder über die Ziellinie bringen.

Zeitdruck: Bei jeder zweiten Raumkarte rückt eine Verfolgergruppe 1 Feld näher. Holt sie die Gruppe ein, startet der nächste Kampf mit 2 kleinen Helfern.

Klassenziele:

| Klasse | Ziel |
| --- | --- |
| Rogue | Kundschafte eine Gefahr aus, bevor die Gruppe eintritt. |
| Bard | Halte verängstigte Begleiter ruhig. |
| Fighter | Fange einen Angriff gegen den Wagen ab. |
| Wizard | Schaffe Licht oder Schutz gegen Schattenmagie. |
| Druid | Finde einen stabilen Weg durch den Pass. |
| Barbarian | Räume ein Hindernis unter Zeitdruck weg. |
